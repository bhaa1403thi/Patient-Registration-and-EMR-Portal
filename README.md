🏥 HealthSync EMR System

A modern Electronic Medical Records (EMR) and Healthcare Management Portal built using React. The system provides role-based access for Admins, Doctors, and Patients, enabling efficient healthcare management through appointment scheduling, patient record management, and secure user authentication.

📌 Project Overview

HealthSync EMR is designed to simplify healthcare administration by providing a centralized platform for managing patients, doctors, appointments, and medical records. The system uses role-based access control to ensure secure and organized healthcare operations.

🚀 Installation
1. Clone Repository
git clone https://github.com/your-username/healthsync-emr.git
2. Navigate to Project Folder
cd healthcare-portal
3. Install Dependencies
npm install
4. Start Development Server
npm run dev
5. Open Browser
http://localhost:5173
